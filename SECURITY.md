# Security policy

## Supported versions

The 1.0 release line targets TYPO3 13.4 and 14.3 on maintained Core patch releases.
Use a PHP version supported by your TYPO3 release, with PHP 8.2 as this package's minimum.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** private reporting feature.
Do not publish exploit details, form definitions, credentials or personal data in a public issue.
If private reporting is unavailable, contact info@linkloot.io privately. The TYPO3 Security Team can also be reached through https://typo3.org/community/teams/security/.

Maintainers must enable private vulnerability reporting before opening the public repository.
This extension does not collect submissions or send telemetry. Transfer files contain form definitions and can include operational configuration such as mail recipients; review files before sharing.
