Usage
=====

Lite
----

Use the library for search, sorting, categories and storage-location filters.
Remove filters individually using their chips or reset all filters together.
Favourites and recent edits are personal. The table header stays visible while
scrolling. Native Core actions remain available according to permissions.

Open a form and choose Metadaten / Metadata to edit its purpose and categories.
Use the normal form Save button. When duplicating, choose whether to copy purpose
and categories; copying never changes the source form.

Pro
---

Pro adds responsibility, person/team, internal notes, My forms, saved personal
and team views, change history, category appearance, import/export and bulk actions.
Shared views do not widen access. The creator or an administrator can change a
shared view; other members may save a copy.

Enable multiple selection to choose rows or the current page, up to 50 forms.
Selection survives pagination and clears when filters change. In Bulk actions,
use the Action dropdown to choose category addition/removal, responsibility or
ZIP export. Concurrent failures remain selected and are reported by name.

Import previews match an existing form by logical identifier, never display name.
Overwrite requires exactly one writable match; New form always creates a separate
identity. Preview approval is time-limited and rechecked on confirmation.

Transfer packages contain definitions only. ZIP exports contain individual JSON
packages; extract them before importing. Imported custom options are validated
and unsupported or unsafe overrides may be rejected.
